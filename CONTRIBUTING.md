# Contributing

Use [DEV/README.md](DEV/README.md) for the current regression and game-only packaging commands. The [full contribution guide](DOCS/CONTRIBUTING.md) explains evidence standards, licensing and the historical release process.

Keep playable operating files in GAME, explanations in DOCS, published experiments in TEST_REPORTS, and developer code in DEV. Do not add private campaign state to the public game kit. A passing file test is not proof of faithful or enjoyable GMing.
