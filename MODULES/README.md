# MODULES

No campaign world ships in this kit. Use New Game.
A module appears here only after ACCEPT.
NEW GAME may build a Sparse, Focused, Detailed, or Custom module. Detailed means selected domains at useful retrieval granularity, not an encyclopedia or mandatory folder tree.

New v0.6 modules propose a campaign promise, fit envelope, six independent play axes, explicit creative-mandate default (`off` unless the operator accepts otherwise), and REVIEW mode under `POLICY.md` → `## Campaign defaults`. The bound run accepts or revises those proposals in its own Campaign Contract; module defaults never authorize a scene or become facts merely because they were written or read.
