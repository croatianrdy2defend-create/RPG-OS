# Add a missing Setting Brief

Cold ADMIN procedure for an explicitly requested addition, including a staged older-campaign upgrade. It creates a compact public orientation from existing accepted stable world authority.

1. Identify the exact module and check that SETTING_BRIEF.md is absent. If a file exists, inspect it and use the refinement/repair procedure instead of overwriting it as missing.
2. Read MODULES/_CONTRACT.md and the narrow public sources needed for the brief. Follow pointers or a bounded subject search; do not inspect private truth, preparation, or campaign history to invent a baseline.
3. Draft the three standard sections: World identity, What is ordinary, Available depth. Preserve the sources' scope, qualifiers, variation, and degree of certainty. List only actual existing cold capabilities; ordinary inventable areas may be described as such.
4. Show the whole compact proposal and note its supporting sources. Clarify unsupported essentials. A requested new world fact is an explicit world-authoring decision, not merely summarization.
5. After clear acceptance, use ADMIN/RECOVERY.md to preserve the affected set and install the brief. In an upgrade or bind, include it in that operation rather than starting a nested transaction.
6. Read back its identity, substance, and declared routes, then finish the operation. Report exactly what changed.

Do not write current state, a roster, secrets, scene plans, or forecast into the brief. Presentation belongs in the accepted campaign agreement. No mandatory script, external inventory, magic acceptance phrase, or fresh-chat ritual is required. If relevant accepted play is unsaved, preserve it before making a baseline change that could affect its interpretation.

For independent agents, include only useful public variation or supported capability constraints. Particular loyalties, beliefs and initialization weights belong in their narrow cold owners. Advertise actual domains, lookup triggers and capability tokens in Available depth; keep exact body paths in the descriptor/index. Missing species or culture folders do not require an invented taxonomy, and a public group tendency does not determine an individual's state.
