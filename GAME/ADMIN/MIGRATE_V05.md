# Older campaign migration alias

For a request to migrate a v0.5 campaign, open `ADMIN/UPGRADE_V07.md`.

v0.7 uses one explicit preservation-and-mapping procedure for older records. The original campaign and its runtime must remain recoverable. The old agreement may be absent and its current-state fields may be incomplete; ask only for material missing facts or grants, preserve uncertainty, and never fill historical gaps from invention.

This file is a compatibility entry point. It does not authorize the former v0.6 migration algorithm or copying blank templates over a live run.
