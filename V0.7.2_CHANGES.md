# RPG OS v0.7.2 — optional preparation and clearer continuity

This is a small experimental update to the v0.7.1 file-operated system. One commercial LLM and an ordinary readable/writable workspace remain sufficient. The public kit contains no campaign world and bundles only Freeform.

## More usable preparation, when it helps

ADMIN/CAMPAIGN_BUILD.md adds original worked examples for two optional aids:

- A recurring person's useful priority, expression example, constraint, and pressure response. Stable anchors remain separate from current objectives, knowledge, and relationships; examples guide portrayal without requiring catchphrases or mannerism quotas.
- A consequential hidden fact's fixed and unfixed parts, relevant knowledge, mistaken beliefs, deliberate lies, and possible evidence. Discovery expectations follow the actual campaign promise; ambiguity does not automatically become an error or a mystery requiring one answer.

NEW GAME selects these only when relevant to the requested depth and accepted authoring/disclosure grants. The notes use existing MODULE/INSTANCE authority. No new required fields, record type, interview round, daily-preparation process, or normal-startup file is introduced. Bound module baselines remain stable; accepted later changes use their existing current-state routes.

## Authority before a consequential draft

LAW now places the existing consequential-authority requirement explicitly before drafting. An established cause, governing procedure, explicit request, or accepted initiative grant supplies the authority; a proposed scene cannot justify itself. Ordinary supporting invention and authorized continuation still work. The instruction stays out of player-facing prose and does not claim mechanical enforcement of the model's internal reasoning order.

## Preserve a claim without making it true

The instance schema explicitly distinguishes an utterance, its actual audience, established private truth, and materially established NPC belief. A false statement is not automatically a deliberate lie. Saving retains the relevant qualification and source. Correcting its truth assessment does not erase that it was said or silently tell its audience the correction.

The existing full-save evidence, correction, and recoverable-write procedures remain in force. They already distinguish unavailable source from invented reconstruction, and failed search from proof of absence; those protections are not new v0.7.2 features.

## Evidence and compatibility

Use [VERIFICATION](VERIFICATION.md) for release checks, [observed trial results](V0.7.2_TRIALS.md) for actual model-operated outcomes, and [the controlled trial protocol](ADMIN/PLAYTEST_V072.md) for the original scenario, inputs, and reporting boundaries. An automated structural suite, a model-operated controlled trial, and a player's experience are different evidence. Passing one does not establish the others.

Matched trials starting from the same prepared facts can assess runtime/save compatibility. They cannot establish that the new cold preparation aids produce better preparation or more enjoyable play. Such claims need separate preparation trials and player feedback.

Valid v0.7.1 campaigns need no save/contract migration and no retrospective completion of optional notes. Install updates in a protected campaign copy and preserve its campaign records. Older v0.7 agreements missing the five clauses still use focused accepted RECALIBRATE; older field-based formats use the existing upgrade procedure.

The update adds no Docker service, search database, mandatory Git workflow, required script, additional model, or compulsory preload of past summaries. The normal resident packet remains the same collection of core, agreement, present, world orientation, and active limits.
