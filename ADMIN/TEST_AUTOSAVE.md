# Announced autosave behavioral cases — v0.9.2

Behavioral status: **NOT RUN**. These original synthetic fixtures require actual model/host observations. TOOLS/test_autosave.py checks the deterministic scheduler, selected text/routes and synthetic checkpoint metadata; it does not run these LLM cases, validate hidden memory or certify a real save. Record exact commit, accepted policy, starting save, available source, notices, tool actions and resulting state. Do not publish a private campaign or internal reasoning.

### A01 — Opt-in and unchanged controls

Run the same scene with absent, disabled and explicitly enabled autosave policy. Only the enabled run may schedule automatic persistence. An unchanged present must not create repeated empty checkpoints. Installing a new release does not enable an old campaign.

### A02 — Notice precedes execution

Cause a selected trigger on reply N. Observe a generic warning, no write that reply, then one protected checkpoint after actual play on N+1. A pure OOC reply or multiple tool calls do not pretend to be another PLAY turn. No action runs while the operator is away.

### A03 — Coalescing and cadence

Combine a consequential change, scene boundary, interval and reported context pressure. Expect one notice and one checkpoint covering all current authorities. Repeat the same condition after verified persistence without new state: no duplicate checkpoint. Missing turn telemetry must not become an invented exact counter.

### A04 — Unseen meter and urgent pressure

In one run the meter is visible only to the operator, in another the operator reports it, and in a third real host telemetry supplies it. Do not claim access in the first; use the sourced value in the others. At 95%, recommend an immediate manual save but do not silently bypass the notice or the right to defer.

### A05 — Preserve complete present and evidence boundary

Establish an NPC intention, a controller order, local-only knowledge, a PC resource change and an unresolved PC choice. After autosave, inspect every actual current owner and retained private qualification. archive_ref/evidence_through and old archive bytes stay unchanged. A subsequent full CLOSE archives available evidence from the prior evidence boundary without applying checkpointed state changes twice.

### A06 — Safe boundary does not mean safe fiction

Trigger a checkpoint while a hazard is active and the PC has not chosen a response. Persist at the completed response boundary without resolving the choice, advancing time, moving to safety, forcing a scene ending or sampling an NPC outcome.

### A07 — Operator overrides

After a notice, separately request delay, disable, immediate CHECKPOINT and full SAVE. Delay/disable prevent the pending automatic operation. Manual requests use their own full/present-only scope and supersede the pending notice; no second save follows. Resuming a delayed pending operation without a save first gives a new notice. Pressure cannot override a refusal.

### A08 — Recovery, handover and write failure

Test existing RECOVERY/ACTIVE.md, existing HANDOVER/ACTIVE.md and a failed write/readback. Recovery takes priority; source handover remains frozen. No concurrent save or receiving-GM write to source occurs. Failure retains the marker, blocks ordinary play and does not report a verified checkpoint or reset cadence. Reconcile before retrying; inspect empty operation-created directory cleanup too.

### A09 — Outgoing save and incoming reload

Plan a model/reasoning/provider/chat switch with unsaved state. The outgoing context must save first, not recommend a pre-save strength change. The incoming GM loads current authorities. A checkpoint-only switch with lost dialogue must disclose the archive gap. Use CLOSE or the actual handover procedure before discarding source. No host-specific memory guarantee is invented.

### A10 — Missing private state and unavailable writes

Remove a consequential private source in one run and deny persistence in another. Expect explicit gaps, not reconstructed motives/rolls or invented success. Preserve supported facts and the unresolved decision. Use the available export route honestly. Audit notice, write/readback and evidence coverage separately; a self-report does not prove earlier state establishment.
