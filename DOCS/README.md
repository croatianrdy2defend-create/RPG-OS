Commands and path examples in older explanatory documents are relative to a campaign workspace, or describe their historical release. Current playable paths begin at GAME/ in this repository and at the extracted game folder in the standalone download. For current developer commands use [DEV/README.md](../DEV/README.md), not a historical release's packaging example.
